# @hvn-oss/storage-postgres-pg

Direct node-postgres persistence adapter for HVN Storage.

## Entry Points

- `@hvn-oss/storage-postgres-pg`
- `@hvn-oss/storage-postgres-pg/migrations`

The v1 package spine intentionally does not expose adapter APIs yet.

## Development

Run `vp run build` to build the package and `vp run test` to run its tests.
