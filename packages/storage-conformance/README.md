# @hvn-oss/storage-conformance

Storage and persistence conformance harnesses for HVN Storage.

## Entry Points

- `@hvn-oss/storage-conformance`
- `@hvn-oss/storage-conformance/storage/v1`
- `@hvn-oss/storage-conformance/persistence/v1`

The v1 package spine intentionally does not expose conformance APIs yet.

## Development

Run `vp run build` to build the package and `vp run test` to run its tests.
